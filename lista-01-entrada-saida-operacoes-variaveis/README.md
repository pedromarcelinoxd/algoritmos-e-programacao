# Algorithms and Programming

Repository containing exercises developed during my studies of **Algorithms and Programming**.

The exercises are written in **C**, with the goal of practicing programming fundamentals and problem-solving skills.

## Exercises

### List 01 – Input and Output, Operations and Variables

1. Double of a number
2. Average of two values
3. Meters to centimeters conversion
4. Approximate number of days lived
5. Division and remainder
6. Triangle area
7. Fahrenheit to Celsius conversion
8. Circumference perimeter
9. Square root and power
10. Average fuel consumption
11. Average vehicle speed
12. Salary calculation
13. Plumber's net payment
14. Weighted average
